# Full-Stack Interview Assignment: Task Management App

## Objective
Build a simple task management application that demonstrates your ability to design and deliver a complete full-stack solution.

## Functional Requirements
The application should allow users to:
- View tasks
- Create tasks
- Modify tasks
- Mark tasks as completed or incomplete
- Delete tasks

## Technical Requirements
- **Spring Boot 3** is required for the backend
- **Vue 3** is required for the frontend
- Define or generate your API using an OpenAPI specification

## Submission
Please provide:
- The GitHub repository of your source code
- The README should explain how to access your OpenAPI specification and your domain model

## AI Usage Guidance
AI tools are allowed for this task (for example, GitHub Copilot, ChatGPT, Claude, and similar tools).
